# ESP32 firmware

The active hardware implementation is in `parkpredict_ultrasonic/`.

Open `parkpredict_ultrasonic/parkpredict_ultrasonic.ino` in Arduino IDE. The sketch folder name and `.ino` filename intentionally match because Arduino requires this convention.

Copy `secrets.example.h` to `secrets.h`, configure Wi-Fi and the gateway token, then follow the root `DEMO-MAKER-START-HERE.md`.
